Quick Start

Get RCPT running in 30 seconds. Generate your first signed receipt, verify it, and inspect the chain.

Install

Python

pip install rcpt

TypeScript

npm install rcpt

Generate a Receipt

Python

from rcpt import RCPTClient, ActionType

client = RCPTClient()

receipt = client.attest(
    action_type=ActionType.INFERENCE,
    output="The capital of France is Paris.",
    model="claude-sonnet-4-5",
)

print(receipt.receipt_id)   # ULID
print(receipt.agent_id)     # did:key:z6Mk...
print(client.verify(receipt))  # True

TypeScript

import { RCPTClient, ActionType } from 'rcpt';

const client = new RCPTClient();

const receipt = client.attest({
  actionType: ActionType.INFERENCE,
  output: "The capital of France is Paris.",
  model: "claude-sonnet-4-5",
});

console.log(receipt.receipt_id);
console.log(client.verify(receipt));  // true

Chain Receipts

Link receipts together to create an audit trail of a multi-step workflow.

r1 = client.attest(
    action_type=ActionType.INFERENCE,
    output="Let me search for that.",
)

r2 = client.attest(
    action_type=ActionType.TOOL_CALL,
    output="API returned 42 results",
    parent=r1.receipt_id,  # chain to r1
)

r3 = client.attest(
    action_type=ActionType.INFERENCE,
    output="Based on the search results...",
    parent=r2.receipt_id,  # chain to r2
)

# Walk the chain
chain = client.get_chain(r3.receipt_id)
# [r1, r2, r3] — full audit trail

Verify

Any party can verify a receipt using only the receipt JSON. No API key, no server, no trust required.

# Different client, different machine — doesn't matter
other = RCPTClient()
assert other.verify(receipt)  # True — uses the DID in the receipt

Core Concepts

The key ideas behind the RCPT protocol.

Receipt

A receipt is a signed JSON document that proves an AI agent took a specific action at a specific time. It contains 7 required fields and any number of optional fields.

FieldTypeDescription
rcpt_versionstringProtocol version ("0.1")
receipt_idstringULID — unique, sortable, timestamped
timestampstringISO 8601 UTC with milliseconds
agent_idstringDID of the signing agent
action_typestringinference, tool_call, transaction, delegation, observation, custom
output_hashstringSHA-256 hash of the output
signaturestringEd25519 signature of the canonical body

Agent Identity

An agent's identity is its Ed25519 public key, encoded as a W3C DID (did:key:z6Mk...). The keypair is generated locally — no registry, no server, no approval needed. The DID is the public key, so anyone can verify receipts signed by that agent.

Chaining

Receipts link to each other via parent_receipt_id, forming a chain that represents a complete workflow. Walking the chain backward from any receipt reconstructs the full decision path.

Anchoring

Batches of receipts are hashed into a Merkle tree. The root is published to Solana. Anyone can verify that a receipt existed at a specific time by checking its Merkle proof against the on-chain root — without trusting the receipt creator.

Privacy

Receipts contain hashes, never raw data. The actual input and output text never appears in the receipt. This makes RCPT GDPR-compatible — delete the source data and the receipt becomes an opaque proof with no recoverable content.

Examples

# Generate a keypair
rcpt keygen --json

rcpt attest "Analyzed quarterly earnings" \
  --model claude-sonnet-4-5 \
  --type inference

echo "Hello world" | rcpt attest - --type inference

rcpt compliance receipts.json --gaps-only

rcpt reputation receipts.json --top 5

Python: RCPTClient

The main entry point for the Python SDK.

from rcpt import RCPTClient, ActionType

# New keypair (default)
client = RCPTClient()

# Persistent identity
client = RCPTClient(private_key="base64url:...")

# With SQLite storage
client = RCPTClient(store="sqlite:///receipts.db")

attest()

Generate a signed receipt.

receipt = client.attest(
    action_type=ActionType.INFERENCE,
    output="Response text",
    input_data="User prompt",        # optional — hashed
    model="claude-sonnet-4-5",       # optional — auto-detects provider
    parent=previous_receipt_id,       # optional — chains receipts
    workflow_id="wf-123",            # optional — groups a workflow
    metadata={"description": "...", "tags": ["tag1"]},
)

verify()

Verify a receipt's Ed25519 signature. Works with Receipt objects, JSON strings, or dicts.

assert client.verify(receipt)           # Receipt object
assert client.verify(receipt.to_json()) # JSON string
assert client.verify(receipt.to_dict()) # dict

get_chain()

Walk a receipt chain backward from a given receipt to its root.

chain = client.get_chain(receipt_id)
# Returns [root, ..., receipt] in chronological order

export()

Export all stored receipts.

json_export = client.export(format="json")
compliance_export = client.export(format="eu-ai-act")

The Receipt dataclass represents a single signed attestation.

receipt.timestamp       # "2026-02-21T02:25:48.513Z"
receipt.agent_id        # "did:key:z6Mk..."
receipt.action_type     # "inference"
receipt.output_hash     # "sha256:64ec88ca..."

# Optional

Python: Reputation

from rcpt import ReputationEngine

engine = ReputationEngine()

# Add receipts
for receipt in receipts:
    engine.add_receipt(receipt)

# Mark third-party verifications
engine.mark_verified(receipt_id)

# Mark disputes
engine.mark_disputed(receipt_id)

# Score an agent
score = engine.score("did:key:z6Mk...")
print(score.score)          # 72.5
print(score.level)          # "Trusted"
print(score.breakdown)      # component scores

# Leaderboard
top = engine.leaderboard(top_n=10)

Merkle Anchoring

from rcpt.hashing import (
    hash_receipt_canonical,
    build_merkle_tree,
    get_merkle_proof,
    verify_merkle_proof,
)

# Hash receipts
hashes = [hash_receipt_canonical(r.to_dict()) for r in receipts]

# Build tree
root, levels = build_merkle_tree(hashes)

# Get proof for a specific receipt
proof = get_merkle_proof(hashes, hashes[0])

# Verify (anyone can do this with just root + proof)
assert verify_merkle_proof(hashes[0], proof, root)

The Merkle root can be anchored on Solana via the RCPT anchor program, providing a trustless timestamp proof.

Solana Program

The RCPT anchor program accepts Merkle roots and stores them as immutable PDAs on Solana.

Instructions

InstructionDescription
anchor_rootAnchor a Merkle root on-chain
verify_proofVerify a Merkle proof against stored root

Cost: ~0.002 SOL per anchor. Batch 1,000 receipts = ~0.000002 SOL per receipt.
